# jj-hunk v0.5.0

Split a large, multi-file diff into focused commits. Select a fix and its tests while leaving unrelated edits in those same files for another commit.

## Hunkset queries

Preview and split matching edit blocks:

```bash
jj-hunk list --format text --query 'added_text("timeout")'
jj-hunk split --query 'added_text("timeout")' "fix: increase request timeout"
```

- Combine changed-text, regex, path, and change-kind predicates with set operators.
- Use the same selection with `list`, `split`, `commit`, and `squash`.
- Select exact occurrences with `id("hunk-<full hash>")`.
- Define named and parameterized aliases in `[hunkset-aliases]` in jj config. Command-line `--alias` definitions override configured aliases.
- Select indivisible additions, deletions, renames, mode changes, and binary changes.
- Continue to use JSON or YAML specs for explicit hunk selection. The README now shows all three formats against the same mixed diff.

Queries select complete edit blocks, not isolated matching lines. Preview the result before applying it.

## Fixes and safety

- List merge revisions against their merged parent tree.
- Distinguish identical edits at different paths or positions with comparison-bound SHA-256 occurrence IDs.
- Evaluate queries against complete content before applying display limits.
- Validate query selections before mutation. Empty query results are a no-op.
- Correct stale-ID handling for added and deleted files in JSON/YAML specs. Reject partial renamed-file specs before mutation; use a hunkset query for those changes.

## Compatibility notes

- Regenerate saved IDs and ID-based specs from `jj-hunk list`. Earlier content/context hashes are not accepted as a fallback. IDs are exact references within a comparison, not identities that follow edits across rewrites.
- The public predicates are `glob()`, `before_glob()`, `after_glob()`, `added()`, `deleted()`, `added_text()`, and `removed_text()`. These replace the earlier development spellings `files()`, `before_files()`, `after_files()`, `creations()`, `deletions()`, `added(text)`, and `removed(text)`.
- `glob()` is a path predicate within hunkset, not the full jj fileset language.
- Occurrence IDs currently require Unix executable-mode inspection. Release binaries are provided for Apple Silicon macOS and x86-64 Linux.
